## 📋 核心考点
1. 会计恒等式：资产=负债+所有者权益 ⭐
2. 借贷记账法（有借必有贷，借贷必相等）⭐⭐
3. 各类经济业务分录（筹资/采购/生产/销售/利润）⭐⭐⭐
4. 账簿登记与对账结账
5. 财务报表编制（资产负债表/利润表/现金流量表）⭐⭐
6. 财务报表分析（比率分析）

💡 避坑：不要一开始就啃CPA难度。大一只需掌握基础会计分录和报表编制，多做课后业务题。⚠️ 分录一定要手写练习，不要只看不练。
