# 统计学

## 🎯 生存指南
> 需要一定的数学基础（高数+概率论）。核心是**假设检验步骤**、**回归分析**和**方差分析**。Excel/SPSS实操能力很重要，不能只会算手算题。

## 📋 核心考点
1. 数据的描述（集中趋势/离散程度/分布形态）⭐
2. 抽样与抽样分布 ⭐
3. **参数估计**（点估计/区间估计）⭐⭐
4. **假设检验**（步骤/单双侧/t检验/卡方检验）⭐⭐⭐
5. **方差分析（ANOVA）** ⭐⭐
6. **相关与回归分析** ⭐⭐⭐
7. 时间序列分析（了解）
8. 统计指数（了解）

💡 学习建议：
- 浙大版（李金昌）教材是这门课最对口的选择
- 假设检验的6个步骤必须背熟并会写
- 回归分析要会看软件输出结果，不只是手算
- 多用Excel/SPSS做实际数据分析，理解比计算更重要
- 概率论没学好的话，这门课会非常吃力，建议先补概率
