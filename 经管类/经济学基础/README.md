## 📋 核心考点

### 微观经济学
1. 供给与需求→市场均衡→弹性计算 ⭐⭐
2. 消费者行为（效用最大化/无差异曲线）⭐
3. 生产者行为（成本曲线/利润最大化）⭐
4. 四类市场结构特征与均衡 ⭐⭐
5. 市场失灵（外部性/公共物品/信息不对称）

### 宏观经济学
6. GDP核算方法
7. IS-LM模型 ⭐⭐
8. AD-AS模型 ⭐⭐
9. 财政政策与货币政策 ⭐
10. 失业与通货膨胀（菲利普斯曲线）⭐

💡 学习建议：每学一个模型，务必亲手画图并标注轴线/曲线移动方向。考试大题基本都是画图+分析。
