## 📋 核心考点
1. 管理职能：计划、组织、领导、控制
2. 管理理论演进：古典→行为→现代→当代
3. 决策理论（理性/有限理性/决策方法）
4. 计划与战略（SWOT分析）
5. 组织设计（结构类型、组织文化）
6. 领导理论（特质/行为/权变/变革型）
7. 激励理论（马斯洛/赫茨伯格/期望理论/公平理论）
8. 控制类型（预算/质量/平衡计分卡）

💡 案例分析答题套路：理论名称→理论要点→结合案例具体分析→得出结论
