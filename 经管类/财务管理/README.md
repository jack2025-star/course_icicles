# 财务管理

## 🎯 生存指南
> ⚠️ **公认的挂科率高**。核心是**货币时间价值**和**估值**。公式多且复杂，不能死记，要理解每个公式的经济含义。强烈建议先修会计学基础。

- B站搜索"财务管理 期末" — 考前突击专题
- **耶鲁金融市场课程**: https://oyc.yale.edu/economics/financial-markets — Robert Shiller教授（英文）

## 📋 核心考点
1. 财务报表分析（杜邦分析体系）⭐
2. **货币时间价值**（现值/终值/年金）⭐⭐ — 一切估值的基础
3. 风险与收益（CAPM模型）⭐
4. 筹资管理（资本结构/杠杆/资本成本）⭐⭐
5. 投资决策（NPV/IRR/回收期）⭐⭐
6. 营运资金管理
7. 股利分配政策
8. 企业估值

💡 避坑：
- 一定要理解公式背后的经济含义，不要死记
- 计算器要用熟（考试允许用科学计算器）
- 先学会计学再学财管，否则看报表会懵
- 多做计算题，财管就是算出来的
- 挂科率高≠学不会，关键是理解+练习量到位⚠️
