# 市场营销

## 🎯 生存指南
> 课程本身较轻松，**小组作业和案例分析**占分多。重点理解STP（市场细分→目标市场→定位）和4P（产品/价格/渠道/促销）。平时分拿满，期末不挂科问题不大。

## 📋 知识框架
1. 市场营销概念与发展
2. 市场环境分析（PEST/五力模型）
3. 消费者行为分析
4. STP战略（市场细分→目标市场→定位）⭐
5. 4P营销组合 ⭐⭐
   - 产品策略（生命周期/品牌）
   - 价格策略（定价方法）
   - 渠道策略（分销模式）
   - 促销策略（广告/公关/销售促进）
6. 数字化营销（新媒体/电商/社交营销）

💡 学习建议：多关注身边品牌的营销活动，尝试用课堂理论分析。小组作业认真做，这门课拿高分不难。⚠️ 不要只背概念，要会结合案例展开分析。
