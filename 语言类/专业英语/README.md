# 专业英语

## 🎯 生存指南
> 核心是**词汇量+文献阅读能力**。不需要追求完美翻译，但要能读懂本专业英文文献的摘要和方法部分。平时多积累专业术语的对照表。

## 📺 视频课程
- 中国大学MOOC搜索"专业英语" — 各高校课程
- B站搜"专业英语" / "学术英语" — 推荐理工科方向的UP主

## 🔗 在线工具
- **Google Scholar**: https://scholar.google.com/ — 搜索英文学术论文
- **CNKI翻译助手**: https://dict.cnki.net/ — 学术术语中英互译
- **Linggle**: https://www.linggle.com/ — 查看单词如何正确搭配使用
- **Ludwig.guru**: https://ludwig.guru/ — 搜索真实语境中的例句
- **Grammarly**: https://www.grammarly.com/ — 写作语法检查
- **DeepL**: https://www.deepl.com/translator — 辅助翻译

## 📖 学术资源平台
- **JSTOR**: https://www.jstor.org/ — 学术期刊数据库（部分免费）
- **arXiv**: https://arxiv.org/ — 预印本论文（计算机/理工科免费）
- **IEEE Xplore**: https://ieeexplore.ieee.org/ — 工程类论文（学校通常有订阅）

## 💡 学习建议
1. **从摘要开始**：先练习读论文Abstract，能读懂80%就算入门
2. **建立术语表**：遇到生词记下来，中英对照，随时复习
3. **精读+泛读结合**：每周精读1篇论文摘要，泛读3-5篇
4. **翻译练习**：找本专业经典教材的英文目录/章节，尝试翻译
5. **口语练习**：尝试用英文介绍自己的专业方向

⚠️ 不要追求一次读懂全文，先能抓住关键词和主旨大意再说。循序渐进。
