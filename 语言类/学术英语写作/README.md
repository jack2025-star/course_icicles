# 学术英语写作

## 🎯 生存指南
> **格式规范 > 文采**。先把论文框架搭好（IMRaD结构），再打磨语言。查重率必须低于学校红线（通常<15-20%），引用格式必须统一。Zotero管理文献能省一半时间。

## 📋 论文结构（IMRaD）
1. Title 标题（简洁准确）
2. Abstract 摘要（背景-目的-方法-结果-结论）
3. Introduction 引言（研究背景→研究问题→研究目的）
4. Literature Review 文献综述（前人研究→研究空白→本研究定位）
5. Methodology 方法（研究设计/数据收集/分析方法）
6. Results 结果（客观陈述+图表辅助）
7. Discussion 讨论（解释结果→与前人对比→局限性→未来方向）
8. Conclusion 结论（简明扼要）
9. References 参考文献（统一格式！）

## ⚠️ 避坑
- **查重是红线**：Turnitin检测，相似度必须低于学校要求
- 引用必须规范标注，抄袭=学术事故
- 避免口语化、缩略语、主观表达
- 段落之间需要逻辑衔接词（However/Therefore/Furthermore...）
- 投稿前至少通读3遍，最好找同学互审

💡 建议：多读目标期刊的高被引论文，模仿其写作框架和表达方式。
