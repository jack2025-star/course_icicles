# 日语入门

## 🎯 生存指南
> **五十音图是地基**，花2-3天必须背熟。然后按"发音→基础语法→日常会话→汉字"的顺序推进。JLPT N5是第一个小目标。

## 📋 学习路线
### 第1阶段：入门（0-N5）
1. **五十音图**：平假名→片假名，每天学一行 ⭐⭐
2. **基础发音**：清音/浊音/半浊音/拨音/长音/促音
3. **基础语法**：です/だ、あります/います、基本动词变形
4. **数字/时间/日期**表达
5. **自我介绍**会话练习

### 第2阶段：进阶（N5-N4）
6. 助词用法（は/が/を/に/で/へ等）
7. 形容词/形容动词变形
8. 过去形/否定形/可能形
9. 常用汉字（200-300个）

💡 建议：
- 五十音图必须背到看到假名能立刻读出来
- 每天10-20个新单词，用Anki间隔重复
- 多听日语歌曲/动漫培养语感
- JLPT考试每年7月/12月，官网: https://www.jlpt.jp/
