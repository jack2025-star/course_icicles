# 大学英语

## 🎯 生存指南
> **词汇量是基础中的基础**。每天背30-50个单词，用APP打卡。听力靠精听+泛听，阅读靠刷真题提速。作文背模板+积累高级表达，翻译练中国文化/社会发展相关话题。

## 📺 视频课程
- 中国大学MOOC搜"大学英语 四级" — 多所高校课程
- B站搜"英语四级" / "大学英语" — 推荐可可英语等UP主

- **可可英语**: https://www.kekenet.com/ — 四六级真题+听力资源
- **扇贝英语/墨墨背单词**: 移动端APP，每日词汇打卡

## 📋 四六级考试要点
1. **听力**（35%）: 短篇新闻/长对话/听力篇章
2. **阅读**（35%）: 选词填空/段落匹配/仔细阅读
3. **写作**（15%）: 议论文/应用文（书信/通知等）
4. **翻译**（15%）: 汉译英（中国文化/社会发展）

💡 备考建议：
- 坚持每天背单词，用APP间隔重复
- 听力精听（逐句听写）+泛听（磨耳朵）结合
- 真题至少刷3遍以上
- 写作积累10个万能句型和高级替换词
- 翻译关注中国文化/科技/经济类话题的英文表达

⚠️ 难度：⭐⭐（四级）| ⭐⭐⭐（六级）
