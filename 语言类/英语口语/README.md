# 英语口语

## 🎯 生存指南
> **开口说比什么都重要**。不要怕犯错，找语伴/参加英语角/自言自语都行。影子跟读法（Shadowing）是提升发音和流利度最有效的方法。

## 📺 视频课程
- B站搜"英语口语" — 推荐英美剧模仿类UP主
- **Rachel's English**: YouTube搜频道名 — 美式发音详细教程
- **BBC Pronunciation**: https://www.bbc.co.uk/learningenglish/english/pronunciation — 英式发音教程

## 🔗 在线资源
- **Forvo**: https://forvo.com/ — 真人发音词典，查任何单词的地道发音
- **YouGlish**: https://youglish.com/ — 在YouTube中搜单词看真实语境发音
- **Elsa Speak**: https://elsa-speak.com/ — AI纠音APP
- **HelloTalk**: APP，找全球语伴聊天
- **Tandem**: APP，语言交换配对
- **Cambly**: https://www.cambly.com/ — 在线外教一对一（付费）

## 📋 训练方法
1. **影子跟读（Shadowing）**: 找一段音频，逐句模仿语调和节奏 ⭐⭐
2. **自言自语**: 每天用英语描述身边事物/当天发生的事
3. **录音回听**: 录下自己说的英语，对比原音找差距
4. **看剧学口语**: 推荐《老友记》《摩登家庭》，开英文字幕跟读
5. **语伴对话**: HelloTalk/Tandem每周至少2次对话

## 💡 话题储备
- 自我介绍（姓名/专业/爱好/家乡）
- 日常场景（点餐/购物/问路/天气）
- 观点表达（同意/反对/举例说明）
- 看图说话/描述图片
- 简单Presentation（1-2分钟主题演讲）
