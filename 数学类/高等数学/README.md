## 📋 最短学习路径
1. 极限（含两个重要极限、洛必达）— 1周
2. 导数与微分（中值定理、泰勒公式）— 1.5周
3. 不定积分（换元法、分部积分法）— 1.5周
4. 定积分（几何物理应用）— 1周
5. 微分方程（可分离/一阶线性/二阶常系数）— 1周
6. 多元函数（偏导数、重积分）— 1.5周
7. 级数（幂级数收敛域、傅里叶）— 1周
8. 刷真题/模拟卷至少3套
