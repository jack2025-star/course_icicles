# 数学建模

## 🎯 生存指南
> 组队是关键！3人各有所长：**编程手+写作手+建模手**。历年国赛/美赛一等奖论文是最重要的学习资料。掌握MATLAB/Python + LaTeX排版就够了。

## 🏆 主要竞赛
| 竞赛 | 时间 | 难度 |
|------|------|------|
| 全国大学生数学建模（CUMCM） | 每年9月 | ⭐⭐⭐⭐ |
| 美国大学生数学建模（MCM/ICM） | 每年2月 | ⭐⭐⭐⭐⭐ |
| MathorCup高校数学建模 | 每年4-5月 | ⭐⭐⭐ |

## 🔗 必备资源
- **CUMCM官网**: https://www.mcm.edu.cn/ — 竞赛通知+优秀论文
- **MCM/ICM官网**: https://www.comap.com/ — O奖论文
- **MATLAB文档**: https://www.mathworks.com/help/matlab/ — 官方教程
- **SciPy文档**: https://docs.scipy.org/doc/scipy/ — Python科学计算
- **Overleaf**: https://www.overleaf.com/ — 在线LaTeX论文排版

1. 线性规划/整数规划
2. 微分方程模型
3. 回归分析/分类模型

## 💡 建议
- 先看3-5篇国赛一等奖论文学习写作框架
- MATLAB或Python至少精通一个
- 从小型竞赛（五一/电工杯）开始练手
- 团队提前磨合，不要赛前临时组队
