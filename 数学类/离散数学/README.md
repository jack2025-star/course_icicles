# 离散数学

## 🎯 生存指南
> 逻辑推理+图论是核心。**命题逻辑的等值演算、谓词逻辑推理、图的遍历与树**是考试高频内容。这门课靠理解+做题，不要指望考前突击。需要一定数学抽象思维能力。

## 📋 最短学习路径
1. **命题逻辑**（等值演算、范式、推理）— 2周 ⭐
2. **谓词逻辑**（量词、推理）— 1.5周 ⭐
3. **集合论**（运算、笛卡尔积、基数）— 4天
4. **二元关系**（性质、闭包、等价/偏序）— 1周
5. **图论**（基本概念、欧拉/哈密顿、树、着色）— 2周 ⭐
6. **组合数学**（计数、递推、容斥）— 1周
7. 代数结构（群/环/域，根据学校要求）— 1周

⚠️ **避坑**：多花时间在命题逻辑和图论上，这两块几乎每张卷子都有大题。做证明题时先模仿教材写法，再逐步独立完成。推荐用Python实现图论算法（BFS/DFS/最短路径）加深理解。
