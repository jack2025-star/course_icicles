## 📋 最短学习路径
1. 行列式（定义、性质、克莱姆法则）— 2天
2. 矩阵（运算、逆、初等变换、秩）— 3天 ⭐
3. 向量组（线性相关/无关、极大无关组）— 3天 ⭐
4. 线性方程组（解的结构）— 2天 ⭐
5. 特征值与特征向量（相似对角化）— 3天 ⭐
6. 二次型（配方法、正定）— 2天
7. 刷同济课后题重点章节 + 往年真题

⚠️ **避坑**：不要花太多时间学"线性空间"理论（除非考研考），期末重点在前5块。用Python(numpy)实现矩阵运算可加深理解。
