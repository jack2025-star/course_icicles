## 📋 最短学习路径
### 概率论（重点⭐）
1. 随机事件与概率（古典概型、全概率/贝叶斯）— 2周
2. 随机变量及其分布（离散+连续、分布函数）— 2周 ⭐
3. 多维随机变量（联合/边缘/独立性、Z=X+Y分布）— 1.5周
4. 数字特征（期望、方差、协方差）— 1周 ⭐
5. 大数定律与中心极限定理 — 3天

### 数理统计（了解）
6. 抽样分布（χ²/t/F三大分布）— 1周
7. 参数估计（点估计/区间估计）— 1周 ⭐
8. 假设检验步骤 — 1周 ⭐
9. 回归分析/方差分析 — 1周

⚠️ **避坑**：不要一开始就啃数理统计部分！先搞定概率论前五章，统计部分自然迎刃而解。茆诗松版比浙大版更难，量力选择。
