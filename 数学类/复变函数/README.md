# 复变函数

## 🎯 生存指南
> 工科选修，难度较大。**留数定理和积分变换**是期末考核心。需要先修数学分析（极限/级数/积分基础）。学不懂建议先看MIT OCW入门。

## 📺 视频课程
- 搜索"复变函数"在中国大学MOOC/B站，找到高校课程
- **MIT OCW 18.04复变函数**: https://ocw.mit.edu/courses/18-04-complex-variables-with-applications-fall-2018/ — 英文，讲解清晰
- **NPTEL复变函数**: 搜索"NPTEL complex analysis" — 印度理工免费课程

## 🔗 工具
- **Wolfram Alpha**: https://www.wolframalpha.com/ — 复数运算、留数计算、积分变换验证

## 📋 学习内容
1. 复数与复变函数基础
2. 解析函数（Cauchy-Riemann条件）
3. 复变函数积分（Cauchy定理/公式）
4. 级数（Taylor/Laurent展开）
5. **留数定理及其应用** ⭐ — 利用留数计算实积分
6. 共形映射
7. Fourier/Laplace变换

⚠️ **避坑**：前修课程不牢（特别是级数和积分），这里会直接劝退。建议先复习数学分析再学。⭐部分为重点。
