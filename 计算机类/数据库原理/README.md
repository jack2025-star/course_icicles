## 📋 最短学习路径
1. 关系模型+关系代数（2天）
2. **SQL语言**（3天）— DDL/DML/嵌套查询/视图 ⭐
3. 数据库设计（ER→关系模式→范式/BCNF）— 3天 ⭐
4. 查询优化（索引、B+树）— 1天
5. 事务管理（ACID、封锁协议）— 2天 ⭐
6. 恢复技术 + NoSQL了解 — 1天

## ⚠️ 避坑
- 不要死记SQL语法，要在数据库里实际跑
- 范式分解是重点难点，多做ER图练习
- 事务的隔离级别（读未提交→可串行化）要理解每种解决了什么问题
