## 📋 最短学习路径
1. 线性表（顺序表、链表、栈、队列）— 1周
2. 树与二叉树（遍历、Huffman、并查集）— 1.5周
3. 图（存储、BFS/DFS、最短路、最小生成树）— 2周
4. 查找（哈希表、二叉排序树）— 3天
5. 排序（快排、归并、堆排）— 3天
6. 刷PAT乙级15题 → 期末稳过

⚠️ **避坑**：不要一上来就读《算法导论》，先掌握上面6个核心知识点再说。
