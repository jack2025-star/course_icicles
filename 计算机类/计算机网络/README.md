## 📋 最短学习路径
1. 五层模型总览（1天）
2. 物理层/数据链路层（PPP、以太网）— 2天
3. 网络层（IP、路由、ICMP、ARP）— 3天
4. 传输层（TCP三次握手、流量控制、拥塞控制）— 4天 ⭐重点
5. 应用层（HTTP、DNS、SMTP、DHCP）— 2天
6. Wireshark抓包练习（2小时）
7. 做真题（至少3套）

## 🔑 核心必背
- TCP三次握手/四次挥手及所有状态
- 滑动窗口与拥塞控制算法
- 路由算法（RIP距离向量、OSPF链路状态）
- DNS递归查询过程
- HTTP 1.1 vs HTTP 2.0区别
